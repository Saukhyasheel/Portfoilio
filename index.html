Built an Azure Function App to optimise vector search pipelines with selective chunk-level indexing and deletion. Files from Blob Storage are chunked, vectorised, and stored in Azure Cognitive Search, while chunk mappings are tracked in Azure Table Storage. This enables targeted updates or deletions without rebuilding the full index, creating a faster, scalable, and production-ready search architecture.
